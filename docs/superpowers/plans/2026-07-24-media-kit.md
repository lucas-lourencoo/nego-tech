> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bilingual, statically generated profile of Lucas's digital presence and creator work.

**Architecture:** Extend the existing typed portfolio content with a focused `MediaKitContent` model, render it through one shared server component, and expose localized App Router pages. Reuse the current editorial CSS Module, navigation shell, metadata helper, and sitemap.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, CSS Modules, `node:test`.

## Global Constraints

- Keep the page distinct from the career-focused About page.
- Use static rounded metrics and static YouTube metadata; add no runtime APIs or dependencies.
- Include no partnership pitch, résumé, pricing, fabricated campaigns, availability language, or commercial results.
- Support English and Portuguese at `/en/media-kit` and `/pt/media-kit`.
- Preserve the existing 800px editorial scale and 16–17px mobile body typography.
