# Uses Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bilingual editorial Uses page and include GitHub among the Contact links.

**Architecture:** Extend centralized typed content with Uses categories, render them through a focused page component, add static localized routes and metadata, then expand the shared navigation and sitemap.

**Tech Stack:** Next.js 16, React 19, TypeScript, CSS Modules, Node test runner.

## Global Constraints

- Uses follows the existing 800px editorial layout.
- Menu order is About, Uses, Contact.
- Internal navigation uses Next.js `Link`.
- External links use official URLs and safe new-tab attributes.
- Contact contains only LinkedIn, GitHub, and Email.
- English and Portuguese routes statically generate.
